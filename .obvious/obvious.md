## What this is

**InputGuard** — a pure-Python library (v0.2.0, PyPI: `inputguard`) that pre-screens user
inputs before they hit an LLM: detects intent (build / debug / optimization / explanation /
feature), scores clarity 0–100, flags gaps, and returns recommendations. Zero runtime
dependencies, zero LLM calls. Python >= 3.9.

It is a **library, not a service** — no server, no port, no database, no CLI, no required
env vars. There is nothing to `docker compose up`.

## Primary user flow

`guard = InputGuard(mode="warning"|"strict")` → `guard.analyze(text)` → detect intent →
apply the intent's rules → clarity score → status by mode:

- warning: `ready` >= 85, `usable_with_warnings` 60–84, `needs_clarification` < 60
- strict: `ready` >= 85, `needs_clarification` 65–84, `blocked` < 65
- Score is mode-independent; only the threshold changes.

Smoke check (paste into a Python shell):

```python
from inputguard import InputGuard
r = InputGuard().analyze("fix my code")
assert r.detected_intent == "debug" and r.status == "needs_clarification" and r.clarity_score == 35
```
